## Proyectos destacados

### Project Games

Aplicación web desarrollada con React y Vite enfocada en la exploración y administración de videojuegos.

El proyecto incluye funcionalidades como:

* catálogo de videojuegos;
* diferentes categorías;
* páginas de detalle;
* navegación con React Router;
* sistema de usuarios y roles;
* panel administrativo;
* creación, edición y eliminación de contenido;
* calificaciones y reseñas;
* almacenamiento local de información;
* diseño responsive.

**Tecnologías:** React, JavaScript, Vite, CSS, React Router, LocalStorage y SessionStorage.

[Ver Project Game](https://github.com/ErianFWD/Project-Game)
